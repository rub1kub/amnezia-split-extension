Routeva 0.9.2 добавляет прямой доступ к российским сервисам и независимый выбор сервера для нескольких пользователей Gateway.

- MAX, банки, российские домены и IP-диапазоны обходят браузерный VPN, включая режим «Весь интернет».
- Правила хранятся на вашем HTTPS-сервере. Сервер обновляет данные ежедневно, расширение проверяет их при запуске и каждые шесть часов. При ошибке сохраняется последняя рабочая версия.
- Начальная копия правил входит в расширение. Новые разрешения браузера не требуются.
- Аккаунты Gateway выбирают узлы независимо; участники не могут менять общие подписки.
- Исправлено зависание API из-за незавершённых TLS-соединений и ложная ошибка проверки прокси при недоступной проверке страны.

Скачайте `routeva-extension.zip`, замените файлы существующего расширения и нажмите «Обновить» на его карточке в `brave://extensions` / `chrome://extensions`. Само распакованное расширение автоматически не устанавливает новую версию; после обновления правила уже синхронизируются автоматически.

Серверная установка и обновление описаны в `gateway/README.md`, установка общих списков — в `gateway/routing/README.md`. Не заменяйте свои пароли, сертификаты и ссылки подписок файлами из примеров.

**AmneziaVPN:** отдельный архив содержит совместимый JSON для импорта на Windows, macOS, Android и iOS. В официальной Amnezia пока нет автообновления такого списка по URL: после скачивания файл нужно импортировать в режим обхода VPN. Этот релиз не добавляет эту функцию в приложение Amnezia.

Если запущен Happ или другой системный VPN, ему также нужны исключения: браузерный `DIRECT` следует маршрутам ОС. Списки не гарантируют распознавание каждого российского сервиса, особенно новых доменов и общих CDN.

Проверено: 43 JavaScript-теста, 23 Python-теста; серверные HTTPS-списки отвечают HTTP 200. Изменение не проверялось на физических Android/iOS-устройствах.
