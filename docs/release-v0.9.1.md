# Routeva 0.9.1 — исправление пинга Gateway

- Исправлен пинг узлов подписок: используется provider-node healthcheck Mihomo, а не глобальный список прокси. В 0.9.0 рабочие узлы могли ошибочно отображаться как недоступные.
- В настройках добавлена кнопка **«Загрузить серверы из Gateway»**. Существующие подписки можно получить после сохранения учётных данных HTTPS-прокси, без повторного импорта ссылки.
- Подключение существующего списка использует только `GET /v1/status`; выбранный удалённый узел не переключается.

Список серверов, поиск, фильтр, сортировка и пинг одного/всех остаются внутри popup. Пинг измеряется по маршруту **Gateway → проверяемый узел → HTTPS-цель**, не включает путь ПК → Gateway и не является ICMP-пингом. Проверка не переключает текущий выход и не отключает VPN. Ошибки и тайм-ауты не выдаются за нулевую задержку.

## Обновление

1. Обновите распакованную папку расширения и нажмите «Обновить» на карточке Routeva в `brave://extensions`.
2. Обновите только Python API по [инструкции Gateway](../gateway/README.md#upgrade-to-091). Не заменяйте секреты, подписки и настройки Mihomo; не перезапускайте работающий туннель.
3. Если список ещё не подключён, сохраните данные HTTPS-прокси во вкладке «Вручную», затем во вкладке «По ссылке» нажмите «Загрузить серверы из Gateway».

Архив для Chrome Web Store подготовлен, но публикация на GitHub не означает публикацию в магазине. Пароли и частные ссылки не входят в исходники и релизные архивы.
