# Routeva 0.9.0 — список серверов и пинг

## Новое

- Полный список серверов прямо в окне расширения: флаги, название, протокол и подписка.
- Поиск, фильтр подписок, сортировка по имени, исходному порядку или задержке.
- Проверка одного узла и всех в текущем фильтре; ограниченная очередь и кнопка «Стоп».
- Результаты сохраняются локально и помечаются устаревшими через пять минут.
- Необязательный пинг при открытии списка, по умолчанию выключен; постоянного фонового пинга нет.
- Включены ранее подготовленные исправления быстрого переключения и сохранения списка при временно пустом ответе Gateway.

## Важно о пинге

Нужен обновлённый **Routeva Gateway 0.9.0**. HTTPS-проверка идёт по маршруту Gateway → проверяемый узел → gstatic.com/generate_204; она не включает путь ПК → Gateway и не является ICMP-пингом. Текущий выход, VPN и настройки прокси не переключаются ради проверки. Ручные HTTP/SOCKS-прокси в этой версии не тестируются. Тайм-ауты/ошибки не выдаются за «0 мс».

Gateway принимает только ID известного узла, использует фиксированный HTTPS URL и максимум четыре параллельных проверки. Секреты и ссылки подписок в релиз не входят.

## Установка / обновление

1. Распакуйте `routeva-extension.zip` в постоянную папку.
2. В `brave://extensions` включите «Режим разработчика» → «Загрузить распакованное расширение» → выберите папку с `manifest.json`. Для уже установленной папки замените файлы и нажмите «Обновить» на карточке.
3. Обновите **только Python API Gateway** по инструкции `gateway/README.md` из `routeva-0.9.0-gateway.zip`. Не заменяйте секреты, подписки или конфигурацию Mihomo.

Архив `routeva-0.9.0-store.zip` подготовлен для загрузки в Chrome Web Store. Публикация на GitHub не означает публикацию в магазине.

Проверки: автоматические тесты JS/Python, аутентифицированный HTTP API с тестовыми данными и UI smoke-тест в отдельном временном профиле Brave. Реальные персональные VPN-подписки в тестах не используются.
